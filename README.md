# Bahram Agent

Bahram is an advanced AI agent system inspired by [Hermes](https://github.com/NousResearch/hermes-agent) from Nous Research.

## Features

- **Self-Improving**: Learns from experience and creates reusable skills
- **Autonomous**: Executes complex tasks with minimal supervision
- **Multi-Platform**: Works across CLI, messaging platforms, and APIs
- **Secure**: Built-in security best practices
- **Reliable**: Comprehensive testing and error handling

## Quick Start

1. Install opencode
2. Configure your API keys
3. Start using Bahram:

```bash
opencode
```

## Commands

- `/analyze <target>` - Deep analysis
- `/review <target>` - Code review
- `/deploy <env>` - Deployment
- `/research <topic>` - Research
