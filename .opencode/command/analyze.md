# Analyze Command

Perform deep analysis of the target. This command triggers comprehensive investigation and provides actionable insights.

## Usage

```
/analyze <target>
```

Where `<target>` can be:
- A file or directory path
- A specific problem or issue
- A system or component
- A technology or framework

## Analysis Process

1. **Understand**: Clarify what needs to be analyzed
2. **Investigate**: Gather information from multiple sources
3. **Analyze**: Identify patterns, issues, and opportunities
4. **Synthesize**: Create actionable summary
5. **Report**: Present findings with recommendations

## Output Format

### Executive Summary
Brief overview of key findings

### Detailed Analysis
- Current state assessment
- Issues identified
- Opportunities discovered
- Patterns recognized

### Recommendations
Prioritized list of actions

### Next Steps
Concrete steps to implement recommendations

## Examples

```
/analyze ./src
/analyze performance issues
/analyze authentication system
/analyze database queries
```

## Integration

This command uses the Bahram Researcher subagent for comprehensive analysis. For code-specific analysis, consider using the `/review` command instead.
