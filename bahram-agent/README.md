# Bahram Agent

A powerful, self-improving AI agent framework.

## Quick Start

```python
from bahram import Agent, Config

# Create agent
config = Config()
agent = Agent(config)

# Run agent
response = await agent.run("Hello, how can you help me?")
print(response)
```
